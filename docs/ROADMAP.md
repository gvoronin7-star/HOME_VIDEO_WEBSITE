## 🛑 Риски и митигация

### Технические риски

| Риск | Вероятность | Влияние | Митигация |
|------|-----------|---------|-----------|
| FFmpeg не установлен на сервере | Высокая | Высокое | Docker-образ с FFmpeg, graceful degradation |
| OpenAI API недоступен | Низкая | Высокое | Mock-режим, fallback на другие LLM |
| Большие файлы видео | Средняя | Среднее | Rate limiting, CDN, оптимизация |
| Базовый размер БД растёт | Высокая | Низкое | Автоматическая очистка, архивация |

### Бизнес-риски

| Риск | Вероятность | Влияние | Митигация |
|------|-----------|---------|-----------|
| Конкуренция с крупными игроками | Высокая | Высокое | Фокус на нише (семейные видео) |
| Изменение политики OpenAI | Средняя | Высокое | Поддержка альтернативных LLM |
| Проблемы с авторскими правами | Низкая | Высокое | Terms of Service, модерация контента |
