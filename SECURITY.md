# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | ✅ Active          |

## Reporting a Vulnerability

Если вы обнаружили уязвимость, пожалуйста:

1. **Не создавайте публичный issue**
2. Напишите на: **security@family-cinema.local**
3. Опишите уязвимость и шаги воспроизведения
4. Мы ответим в течение 48 часов

## Security Best Practices

### Для разработчиков

- **Никогда не коммитьте `.env` файлы**
- Используйте `.gitignore` для чувствительных файлов
- Регулярно обновляйте зависимости: `npm audit`
- Используйте `.env.example` для шаблонов

### JWT

- Секрет хранится в переменной окружения `JWT_SECRET`
- Срок действия токена: 7 дней (настраивается)
- В продакшене используйте сильный секрет (32+ символов)

### Файлы

- Загруженные файлы проверяются через Sharp
- Максимальный размер: 10 МБ (настраивается)
- Автостарые файлы удаляются через FILE_RETENTION_DAYS

### БД

- Sequelize ORM защищает от SQL injection
- Используйте PostgreSQL в продакшене
- Регулярно делайте бэкапы volume `postgres-data`
